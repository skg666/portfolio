# Modern Developer Portfolio Website

A premium, responsive, and sleek developer portfolio website designed for **Saurav Kumar** (AI/ML Enthusiast, Aspiring Software Engineer, and Microsoft Learn Student Ambassador). 

Live Preview local command: `python -m http.server 3000`

---

## 🚀 Key Features

- **Premium Modern Design**: Built with a sleek dark mode theme, sky-blue (`#38bdf8`) & emerald (`#34d399`) accent colors, glassmorphism components, and subtle linear gradients.
- **Dynamic mouse-tracking blobs**: Blur overlay animations that follow cursor trajectories for immersive interaction.
- **Interactive Certificate Showcase**: Custom-built, responsive lightbox modal that displays credentials and official certificates locally when clicked.
- **Clean Structure Split**: Restructured Achievements section dividing milestones into **Coding Milestones** (with direct Codeforces and LeetCode profile views) and **Industry Certifications**.
- **Interactive Metrics**: Floating statistics cards showing real-time animated increment counts.
- **Aria-accessibility & Keyboard support**: Full screen overlays and modals configured to open/close using focus markers and the `Escape` key.
- **Fully Responsive**: Optimized fluid CSS breakpoints for desktop, tablet, and mobile displays.

---

## 🛠️ Built With

- **HTML5**: Semantic tags, accessibility attributes, and SEO structures.
- **CSS3 (Vanilla)**: Curated custom styling variables, custom scrollbar tracks, grid/flex layouts, and keyframe animations.
- **JavaScript (ES6)**: Hamburger navigation toggle, active scroll link observers, count animator, and lightbox modal triggers.
- **Icons**: Lucide Icons CDN.

## 💻 Getting Started

### Local Setup
Since the project is built with static assets (HTML/CSS/JS), you can run it locally without installing any web frameworks.

1. **Clone or Download** this folder.
2. Open a terminal in the folder directory and start a local HTTP server:
   ```bash
   # Using Python
   python -m http.server 3000
   
   # Or using Node (if installed)
   npx http-server -p 3000
   ```
3. Open your browser and navigate to `http://localhost:3000`.
